# SDR
Учебная практика "SDR" 2026-2027г.

Студент 3 курса Петров Т.И. группы ИКС-431

## Общая информация и инструкция по установке

### Папка reports
- Отчёты по проделанной работе

### Папка third_party
- Cабмодули на используемые библиотеки

### Папка dev
- Основной проект: главный файл main.cpp, CMake файл, python скрипты для отрисовки графиков и обработки записи (main.py, plots.py) и скрипт для компиляции проекта (run.sh)

### Инструкция по установке и компиляции
- Склонируйте репозиторий с флагом `--recursive`: `git clone --recursive <ссылка на репозиторий>`
- Установите библиотеки SoapySDR и драйвер для Adalm Pluto (см. практику №3, №4). Проверьте, что плата видна: `SoapySDRUtil --find`
- Запустите файл `dev/run.sh` для компиляции
- Перейдите в папку `dev/build`, запустите исполняемый файл и укажите, что нужно использовать (передатчик или приёмник)
- Например: `./main Tx --freq 1 bpsk` или `./main Rx --freq 1`
- Для обработки записи нужен Python 3 с библиотеками `numpy` и `matplotlib`: `pip install numpy matplotlib`
